# **Personal Portfolio**

I started learning web development about a year ago. Since then, I've been working on personal projects, exploring different technologies, and improving my skills along the way.

This portfolio is where I showcase my projects and some of what I've learned so far. It was built using HTML, CSS, and vanilla JavaScript, with a focus on responsive design and interactive interfaces.

## About Me

I work on both frontend and backend functionality, but I'm particularly interested in creating responsive, interactive interfaces. I prefer vanilla JavaScript because I find it more straightforward and have more experience with it than frameworks like React, although I'm also open to using frameworks depending on the project.

I try to keep my code organized and make sure I understand the technologies I'm using.
